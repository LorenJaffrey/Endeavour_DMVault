# `=this.file.name`
Dein [[Zauberattribut]] bestimmt, wie wirkungsvoll deine Zauber sind. 

Es beeinflusst:
- Den [[Zauberrettungswurf-Schwierigkeitsgrad|Zauberrettungswurf-SG]] deiner Zauber
- Den Modifikator für deine [[Zauberangriffswurf|Zauberangriffswürfe]]

Welches Attribut du nutzt, hängt von deiner Klasse ab:

| Klasse            | Attribut zum Zauberwirken |
| ----------------- | ------------------------- |
| [[Klangweber]]    | [[Verstand]]           |
| [[Kleriker]]      | [[Entschlossenheit]]              |
| [[Naturalist]]        | [[Entschlossenheit]]              |
| [[Fluchwirker]] | [[Verstand]]           |
| [[Arkanist]]      | [[Verstand]]           |
| [[Paladin]]       | [[Präsenz]]              |
